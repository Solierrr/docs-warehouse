# Fluxo de trabalho

Conventional Commits em inglês e minúsculas (`feat:`, `fix:`...), branch `tipo/descricao-curta` e PR com o modelo do repositório. `main` é a base de trabalho; a `qa` recebe a sincronização da `main`.
