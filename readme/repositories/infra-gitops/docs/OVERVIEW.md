# Visão de produto

O repositório reúne a configuração dos componentes que atendem a plataforma no cluster. Ele permite revisar uma mudança antes da publicação, conhecer o estado desejado e recuperar uma configuração anterior pelo histórico.

Uma alteração aprovada pode iniciar uma atualização automática do ambiente. Recursos removidos da configuração podem ser removidos do cluster. Alterações feitas diretamente no ambiente podem ser desfeitas pela sincronização.

A existência de um componente nos arquivos não comprova que ele está saudável ou disponível no ambiente atual. <!-- PENDENTE: 1 -->
