# Visão de produto

A borda oferece navegação por idioma e uma página temporária quando a aplicação não pode ser acessada. A preferência considera o endereço da página, a escolha salva e o idioma do navegador.

O visitante pode trocar entre português, inglês e espanhol. A troca preserva identificadores e parâmetros das rotas conhecidas. A página temporária não é armazenada em cache.

Caminhos de sondagem recebem resposta local e podem levar a uma verificação de acesso pela proteção da borda. A lista não deve ser tratada como bloqueio permanente. A ativação efetiva depende da configuração externa. <!-- PENDENTE: 1 -->
