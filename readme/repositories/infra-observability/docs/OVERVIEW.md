# Visão de produto

A visualização operacional permite à equipe consultar métricas, registros e rastros dos serviços. A instância atual é configurada em outros repositórios, e este ainda conserva o molde inicial.

Não há uma capacidade exclusiva de produto implementada nesta main, e o repositório continua como a base da configuração de visualização, ao lado do GitOps, que publica a instância, e do coletor, que mantém os painéis.
