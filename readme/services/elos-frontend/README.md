# Páginas e telas do projeto

[![License](https://img.shields.io/github/license/Solierrr/elos-frontend)](https://github.com/Solierrr/elos-frontend/blob/main/LICENSE)
[![GitHub Last Commit](https://img.shields.io/github/last-commit/Solierrr/elos-frontend)](https://github.com/Solierrr/elos-frontend/commits)
[![GitHub Pull Requests](https://img.shields.io/github/issues-pr/Solierrr/elos-frontend)](https://github.com/Solierrr/elos-frontend/pulls)
[![Release](https://img.shields.io/github/v/release/Solierrr/elos-frontend)](https://github.com/Solierrr/elos-frontend/releases)

Este repositório reúne as páginas do projeto exibidas no navegador: a página inicial, que apresenta a proposta de conectar compradores e fornecedores de equipamentos fotovoltaicos, e as telas de entrada, recuperação de senha, apresentação da equipe e gerenciamento de usuários. As páginas são estáticas e não exigem instalação nem etapa de construção. Parte das telas ainda está em desenvolvimento em branches separadas.

## Aprofunde-se no Projeto!

- [ARCHITECTURE.md](https://github.com/Solierrr/elos-frontend/blob/main/docs/ARCHITECTURE.md), organização das páginas, estilos e scripts, e como a tela de gerenciamento fala com o serviço de cadastros.
- [RUNNING.md](https://github.com/Solierrr/elos-frontend/blob/main/docs/RUNNING.md), como abrir as páginas localmente e impedimentos conhecidos.
- [STATUS.md](https://github.com/Solierrr/elos-frontend/blob/main/docs/STATUS.md), o que cada branch contém e pendências conhecidas.
